## ▶️ How to Run

1. Make sure Python 3 is installed:
   ```bash
   python --version
   ```
2. Clone this repository:
   ```bash
   git clone https://github.com/your-username/python-basics.git
   ```
3. Go into the folder and run any program:
   ```bash
   cd python-basics
   python 01_bill_calculator.py
   ```
